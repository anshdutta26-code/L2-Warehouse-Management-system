# StockDesk for a separate firm

The new Streamlit stock, BOM and invoicing app is in [StockDesk](StockDesk).

Deploy **StockDesk/app.py** from branch **main** in Streamlit Community Cloud.
See [deployment instructions](StockDesk/DEPLOYMENT.md) and [Google Sheets setup](StockDesk/START_HERE.md).

Includes a replaceable [Word invoice template](StockDesk/templates/invoice.docx), in-app rendered invoice preview, and Word/PDF downloads.

The root app.py and page_modules directory are the upstream warehouse reference fork. They are not the new firm's app. Upstream: https://github.com/pantamit2003/L2-Warehouse-Management-system

No production credentials or business records are included. Hosting and Google Sheets must still be configured before live use.
